# Task: Write Follow-Up Email

Recipe for follow-ups — explicitly classified by lead status so the message matches what actually happened, not a generic "just checking in".

## When to use this

User asks to write a follow-up, an email 2/3, a "bump", a re-engagement message, or anything for a lead who didn't respond to a previous touch.

## Inputs required

- **Original sequence** that was sent (at minimum: Step 1 copy + how many steps total)
- **Lead status** (the most important input — see Type matrix below)
- **Time elapsed** since last contact
- **ICP and offer context** (re-confirm if not provided)

## The Type matrix — pick one

This is the single most important decision. The type determines tone, length, and whether to send at all.

| Type | Lead status | Behavior | Cadence rule |
|---|---|---|---|
| **A** | No reply to initial sequence, but engaged (opens/clicks) | Soft re-engage, NEW angle | Max 1 per contact per quarter |
| **B** | Replied once, then went cold | Reference prior conversation + new value | Send within 5-10 days of last reply |
| **C** | Expressed interest but didn't book | Direct, < 50 words, remove friction | Send within 48 hours |
| **D** | Timing objection (e.g. "circle back in Q3") | Triggered on the date they named | Send on the agreed date, treat as warm |

If the lead has zero engagement (no opens, no clicks, no reply) → **don't send a follow-up**, send the next planned cold step instead. A follow-up requires an engagement signal.

## Principles (non-negotiable)

- **Every follow-up adds new value or doesn't get sent.** "Just checking in" is the default failure.
- **Same thread** for Type A/B/C/D — never start a new thread on follow-up
- **Change the value prop between emails**: Email 1: save money → Email 2: make money → Email 3: save time (or invert based on persona)
- **Type C has the highest conversion** of any follow-up — never let these sit
- **After Type A with no response: close the thread.** Don't keep stacking

## Process

1. Identify the Type from the matrix above. If unclear, ask the user for the specific engagement signal.
2. Pull the original sequence's last touch — note the value prop, the CTA, and the angle. The follow-up must NOT repeat any of these.
3. Pick a new value prop or angle (rotate through save money / make money / save time / reduce risk / unlock new outcome).
4. Draft per Type:
   - **Type A** — open with new context (industry stat, recent event, peer outcome). Don't reference "following up". One sentence problem, one sentence proof, one CTA.
   - **Type B** — explicit reference to prior reply ("when we spoke about X"), one new piece of value (case study / stat / company-specific news), soft re-ask.
   - **Type C** — under 50 words, scheduling-oriented. Offer a time directly OR drop a Calendly link. Tone = "want to make this easy for you".
   - **Type D** — reference the timing they named ("you mentioned circling back after the Q3 board"), reference the conversation, and treat them like a warm lead.
5. Self-check:
   - Does this add new value? If not, kill it.
   - Is it shorter than the original? Type B/C should be — Type A can match length.
   - Is the CTA different from the original? Should be a different ask, not a repeat.

## Output format

```
Follow-up: [lead name / company]
Type: [A / B / C / D]
Last contact: [date]
Send on: [date or trigger]
Original sequence reference: [Email 1 of 3 / Reply on date X / etc.]

NEW VALUE PROP / ANGLE: [one line — what's different from the original touch]

MESSAGE
Subject: [Re: original subject — same thread]
---
[drafted follow-up]
---

Word count: [n]
What's new: [one line — case study / stat / event / direct ask / etc.]
Next action if no reply: [close thread / one more try / mark nurture]
```

## Pass criteria

- Type matches lead status
- New value prop is named (not a repeat of original)
- Word count: Type A 60-90, Type B 60-90, Type C < 50, Type D 60-90
- Same thread (Re: original subject)
- One CTA only, different from original

## Common failures

- **"Just checking in"** — kill the email, do not send
- **Repeating the original value prop** — rotate to a new one
- **Type A loop** (multiple Type A follow-ups stacking) — after one Type A with no response, close
- **Type C with multi-paragraph copy** — strip to under 50 words, focus on scheduling
- **New thread on follow-up** — always Reply, never new
