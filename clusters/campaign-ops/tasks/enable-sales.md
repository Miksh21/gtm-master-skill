# Task: Enable Sales to Run the Campaign ("Campaign in a Box")

**The principle:** you can have the best campaign idea in the world, but if sales doesn't care, it flops. Growth's job isn't done when the campaign is built — it's done when the seller can execute it with **zero friction**. Package every program so the rep's action is the simplest possible.

## Inputs

- The campaign/play (sequence, target list, signal, offer)
- The seller's daily context and tools
- Complexity level — is this a brand-new use case the rep has never sold?

## Process

1. **Reduce the ask to one obvious action.** "Post this," "send these 10 invites," "work these tasks." If it needs a doc to explain, it's too big.
2. **Pre-build the assets the rep would otherwise have to make:**
   - Ready-to-send copy / posts — the "Monday playlist": hand the rep the exact thing to post or send this week.
   - Pre-filled calendar invites / templates.
   - The list, already enriched + scored + routed to the right rep.
3. **Enable for complex / new plays.** If it's a use case the rep has never sold, run a 30–60 min session on *why the buyer cares* before asking them to send anything. Skipping this is how a good play dies on contact.
4. **Make the value to the rep explicit.** What's in it for *their* number — more meetings, warmer leads, less admin?
5. **Instrument adoption.** Track whether reps actually used it; chase non-adoption as a real failure mode, not a "they'll get to it."

## Output

A one-page "campaign in a box" per rep:
- The action (1 line)
- The assets (links: copy, list, invites)
- Why the buyer cares (2–3 bullets)
- Why it helps the rep's number (1 line)
- Where replies / results land (Slack / CRM)

## Pass criteria

- A rep can execute in **< 10 minutes** without asking a question.
- Every Tier-1 action has a pre-built asset (no "write your own opener").
- Complex / new plays have an enablement session scheduled **before** launch.
- Adoption is tracked, not assumed.
