# Task: Launch a Newsletter (Positioning → Landing Page → Welcome Flow → First Issues)

> Source: swan-gtm/gtm-skills (daniel-bustamante) · MIT · imported 2026-07-28 · external content, unreviewed

Recipe for taking a newsletter from zero to shipping: value prop, name, landing page copy, welcome gift, welcome email, 5-email welcome sequence, and the first content calendar.

## When to use this

User wants to start a newsletter, position or rename an existing one, fix a landing page that doesn't convert, build the welcome sequence, or asks "what should my newsletter be about". Also for auditing an existing newsletter against this system.

## Inputs required

Ask for anything missing before drafting (one question at a time for interviews, not a wall):

- **Niche and target reader** (specific: role, industry, situation, not "founders")
- **The transformation** the reader gets, and their top 2-3 pain points
- **Frequency** (weekly default; never longer than 2 weeks)
- **What they sell** (the paid offer the newsletter ultimately feeds; can be "nothing yet")
- **For the analysis format**: what service they provide and their 2-4 main client deliverables
- Any existing assets: subscriber count, best content pieces, credentials, origin-story bullets

## Principles (non-negotiable)

- **Positioning before content.** No landing page, name, or issue gets written before the value prop exists.
- **Value prop formula**: "Every [frequency], you'll get [what] so you can [specific benefit] without [pain]." 1-2 sentences. Ban "tips/insights/strategies".
- **Name**: 2-4 words, says what it is AND who it's for.
- **Landing page**: Rule of One (one action, no nav/footer/social), form above the fold on mobile, 40-60% opt-in is the bar.
- **Welcome email always contains the reply ask** (specific word + incentive): it trains mailbox providers and protects deliverability for every future send.
- **Sequence sells only after value**: value → proof → expertise → story → pitch. Email 5 is the first pitch, never earlier.
- **Welcome gift**: solves one urgent problem in under 30 minutes, congruent with the value prop.
- No em-dashes, no corporate speak, paragraphs of 1-3 sentences, write to one person.

## Process

1. **Value prop.** Interview (niche, audience, transformation, pain, frequency, differentiator). Generate 3 variations: outcome-led, pain-led, mechanism-led. User picks.
2. **Name.** 10-15 candidates across outcome-driven / audience-driven / mechanism categories. Recommend top 3 with one-line rationale.
3. **Format decision.** Service provider or consultant → recommend the analysis format (weekly breakdowns of a signature asset); pick the asset from their client deliverables and build the breakdown framework checklist (per element: what good looks like, common pitfalls, why it matters). Otherwise → pick a core format (roundup, one-framework-per-issue, case-study).
4. **Landing page copy.** 4 elements: audience callout, outcome-led headline, 3-5 concrete value bullets, 3-6 word CTA. Plus 3 headline variants (curiosity / pain / social proof) for A/B. Append the 3 design rules as a reminder note.
5. **Welcome gift.** 10 ideas from the 9 lead-magnet formats, each with title, format, core promise, why it converts, time to value. User picks one to build.
6. **Welcome email.** The 6-step formula (reinforce decision + social proof, restate value, expectations, reply ask with incentive, instant-value PS link, optional low-ticket offer). 300-500 words.
7. **Welcome sequence.** All 5 emails: Warm Welcome, Greatest Hits, Biggest Misconception, Origin Story, Soft Pitch. Respect per-email length bands and structures from the knowledge file.
8. **Content calendar.** First 8 issues mapped using the 6-category mix (educational 2-3, story 2, contrarian 1-2, curated 1, engagement 1, promotional 1); batching system (analyze one day, write another).

Steps are independent enough to run solo when the user asks for just one (e.g. "write my welcome sequence": run steps 6-7 only, interviewing for missing context).

## Output format

Per step, copy-paste-ready blocks, clearly labeled:

```
VALUE PROP (chosen): ...
NAME (top 3 + rationale): ...
LANDING PAGE: [callout / headline / bullets / CTA] + [3 headline variants]
WELCOME GIFT (chosen spec): ...
WELCOME EMAIL: subject + preview + body
SEQUENCE: EMAIL 1..5, each with subject + body
CALENDAR: 8 issues with category, working title, angle
```

End with a Quick Reference Card: value prop, name, format, gift, publishing schedule.

## Pass criteria

- Value prop passes the structure check (frequency + what + benefit + pain removed) and contains zero banned vague words
- Every landing-page bullet names a tangible deliverable
- Welcome email contains the reply-word ask AND an incentive AND an instant-value link
- No email in the sequence except #5 contains a pitch
- Sequence emails within length bands (200-300 / 250-350 / 300-400 / 350-450 / 300-400 words)
- Calendar has no two consecutive issues from the same category

## Common failures

- **Value prop lists topics instead of a result** ("marketing tips weekly"): rewrite around the transformation
- **Clever name that doesn't say what it is**: clarity wins; test on a stranger
- **Welcome email skips the reply ask** because it "feels gimmicky": it is a deliverability mechanism, keep it
- **Origin story reads like a resume**: restart from one specific pre-transformation moment
- **Pitching in emails 1-4**: move every offer mention to email 5's structure
- **Landing page with nav bar and social links**: Rule of One, strip everything
