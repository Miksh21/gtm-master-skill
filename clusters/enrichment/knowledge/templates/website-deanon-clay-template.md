# Clay Template — Website Visitor De-Anonymization

Concrete copy-paste pattern: website visitor de-anon tool (Warmly / RB2B / Albacross) → Clay webhook → enrich (contact + company) → score with Clay formula → Slack alert on Tier 1 → tier-routed outreach (HeyReach for Tier 1 LinkedIn, Instantly for Tier 2/3 email).

## When to load

- "We deanonymize website visitors but don't act on the data"
- "Set up Warmly / RB2B / Albacross + Clay pipeline"
- Building the highest-conviction 1st-party intent signal: declared website visit

## Why this matters

Website visit = strongest declared intent signal available (the person actively chose to visit). The deanon tools (Warmly, RB2B, Albacross) close the "anonymous pageview" gap. But the data is useless without an action pipeline — most teams capture the visit and nothing happens.

This template wires deanon → enrichment → score → alert → outreach in under 30 minutes.

---

## The pipeline

```
Website visit → Warmly/RB2B/Albacross deanonymization
        ↓ (webhook)
Clay table: company domain + contact email + pages visited + timestamp
        ↓
Auto-contact enrichment: LinkedIn URL + role/seniority + LinkedIn follower count + geography
Auto-company enrichment: industry + size + geography + business model + funding
        ↓
Clay formula: tier score (firmographic + behavioral)
        ↓
Tier 1 → Slack alert (rich payload) + HeyReach LinkedIn outreach
Tier 2/3 → Instantly email automation
```

## Setup steps

### Step 1 — Add tracking snippet to website
- Get the tracking code from Warmly (or RB2B / Albacross)
- Place in the `<head>` of your site
- Publish

### Step 2 — Create Clay table from template
- Locate the published Clay template URL
- Click "Create table using template"
- Pick the workspace

### Step 3 — Connect the de-anon tool
- Open the new Clay table
- Locate the **webhook URL** generated by the template
- In Warmly / RB2B / Albacross:
  - Open integration/webhook settings
  - Paste Clay webhook URL
  - Map required visitor fields (domain, email if available, pages, timestamp)
  - Save + activate

### Step 4 — Verify
- Visit your website yourself or have a teammate visit
- Confirm new rows in the Clay table
- Required fields populated:
  - Company domain
  - Contact email (if individual-level deanon available)
  - Pages visited
  - Visit timestamp
- Confirm repeat visits create new events or update existing records (per template config)

### Step 5 — Auto-enrich (template does this)

The template should automatically enrich:

**Contact-level:**
- LinkedIn profile URL
- Role + seniority
- **LinkedIn follower count** ← unusual but valuable priority signal
- Geography

**Company-level:**
- Industry + sub-industry
- Company size (headcount)
- Geography
- Business model
- Funding status

### Step 6 — Customize scoring
- Review the formula columns in the table
- Default tier logic provided by template
- Customize for your:
  - ICP (which firmographics matter)
  - Market (B2B SaaS scoring ≠ services company scoring)
  - Deal size (enterprise vs SMB weights differ)
  - Sales motion (long enterprise cycle vs short SMB cycle)
- Tiers (default):
  - **Tier 1:** Strong fit (high firmographic + high page intent)
  - **Tier 2:** Good fit
  - **Tier 3:** Low fit

Scoring updates automatically as enrichment data refreshes.

### Step 7 — Slack alerts on Tier 1
- Connect Slack workspace to Clay
- Select channel for Tier 1 visitor notifications
- Alert payload should include:
  - **Company name + tier**
  - **Contact name + role**
  - **LinkedIn + company details**
  - **Funding info**
  - **Pages visited** (the visit context)

### Step 8 — Tier routing to outreach
- **Tier 1:** LinkedIn outreach via HeyReach + optional cold call via BetterContact phone enrichment
- **Tier 2/3:** Automated email via Instantly

## The LinkedIn follower count priority signal

This is an unusual but valuable detail in the workflows.io template. **Why include LinkedIn follower count:**

- A 10K+ follower visitor = potential category influencer (may drive multiple buying decisions, or refer)
- A 50K+ follower visitor = high-priority outreach (they have audience leverage)
- A typical-follower-count visitor = score on firmographics alone

This gives you a "media value" overlay on the deanon signal that most templates miss.

---

## Stakeholder expansion (the Tier 1 unlock)

**The deanon often catches a junior employee.** The actual buyer is upstream. Tier 1 routing should include:

1. **Slack immediate alert** (Tier 1 visit detected)
2. **Identify decision-makers + champions** at the same company (Findymail + BetterContact for those)
3. **Multi-channel outreach** to the expanded list, not just the original visitor

This is the difference between "deanon delivers a contact" and "deanon delivers a *deal opportunity*."

## Tools

- **Warmly** — primary recommendation (company + contact deanon, intent layering)
- **RB2B** — US-focused contact-level deanon
- **Albacross** — alternative deanon platform
- **Clay** — orchestration + scoring
- **Findymail** — email verification + waterfall
- **BetterContact** — phone waterfall (Tier 1 cold call)
- **HeyReach** — Tier 1 LinkedIn outreach
- **Instantly** — Tier 2/3 email automation
- **Slack** — Tier 1 alerts

## Common failures

- **Tracking snippet placed in `<body>` not `<head>`** — fires inconsistently across page loads
- **Default tier scoring not customized** — works for some, but most teams need to tune for their ICP
- **No stakeholder expansion** — outreach to the original visitor only misses the buyer
- **Slack payload too thin** — without pages visited + phone + LinkedIn, the alert is noise
- **Repeated visitor floods** — every page refresh creates a new row. Use de-duplication or "update existing" logic, not "always insert new."
